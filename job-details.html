About the Role

Stripe is looking for a passionate Junior Frontend Engineer to join our Dashboard and UI infrastructure team. In this role, you will collaborate with designers and senior engineers to build fast, intuitive, and accessible user interfaces that empower millions of businesses around the world.

This is an ideal role for university graduates and junior engineers eager to deepen their expertise in modern frontend technologies, design systems, and web accessibility standards (WCAG).

Key Responsibilities

  • Develop responsive and accessible web interfaces using semantic HTML5 and Tailwind CSS.
  • Collaborate with product designers to implement clean, consistent UI components.
  • Write well-documented code adhering to industry web standards and WCAG 2.1 AA guidelines.
  • Participate in code reviews and contribute to the internal component library.
  • Test web applications across multiple screen sizes and desktop/mobile browsers.

Required Technical Skills

HTML5 Tailwind CSS JavaScript (ES6+) Git & GitHub Web Accessibility (WCAG) Responsive UI
